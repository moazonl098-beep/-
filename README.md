# تفوق - جدول المذاكرة الأسبوعي 📚

تطبيق PWA (Progressive Web App) جاهز للاستضافة على GitHub Pages، وتقدر تثبّته على شاشة موبايلك زي أي تطبيق عادي.

## محتويات المجلد

```
index.html              الصفحة الرئيسية للتطبيق
manifest.json           إعدادات التطبيق (الاسم، الأيقونة، الألوان)
service-worker.js       يخلي التطبيق يشتغل حتى من غير إنترنت
icons/
  icon-192.png
  icon-512.png
  icon-512-maskable.png
  apple-touch-icon.png
  favicon-32.png
  favicon-48.png
```

**مهم:** ارفع كل الملفات دي بنفس الأسماء وبنفس الترتيب (فولدر icons لازم يفضل فولدر منفصل)، من غير ما تغيّر أي اسم، عشان الروابط بينهم تفضل شغالة.

## خطوات النشر على GitHub Pages

1. **اعمل حساب على GitHub** (لو مفيش عندك): [github.com](https://github.com)

2. **اعمل Repository جديد:**
   - دوس على "+" فوق يمين الصفحة → "New repository"
   - اكتب اسم زي `study-schedule` (أي اسم بالإنجليزي من غير مسافات)
   - خليه **Public**
   - دوس "Create repository"

3. **ارفع الملفات:**
   - في صفحة الـ repository، دوس "uploading an existing file" أو "Add file" → "Upload files"
   - اسحب كل الملفات والفولدر `icons` بالكامل
   - دوس "Commit changes" تحت

4. **فعّل GitHub Pages:**
   - روح لـ "Settings" في الـ repository
   - من القائمة الجانبية، دوس "Pages"
   - تحت "Source" اختار: Branch = `main`، الفولدر = `/ (root)`
   - دوس "Save"
   - استنى دقيقة أو اتنين، هيظهرلك رابط شكله كده:
     `https://اسم-حسابك.github.io/study-schedule/`

5. **افتح الرابط من موبايلك (Chrome):**
   - الصق الرابط في المتصفح
   - دوس على قائمة التلات نقط (⋮) → **"Install app"** أو **"Add to Home screen"**
   - هتلاقي أيقونة "A+" على شاشتك الرئيسية باسم "تفوق"، وبتفتح كتطبيق كامل من غير شريط المتصفح، وتشتغل حتى من غير نت

## ملاحظات

- كل بياناتك (المهام، التقدم، الامتحانات...) بتتخزن في متصفح جهازك بس (localStorage). لو غيرت جهاز أو متصفح، استخدم زرار "تصدير البيانات" جوه التطبيق قبل ما تسيب الجهاز القديم، وزرار "استيراد البيانات" على الجهاز الجديد.
- لو عدّلت أي ملف بعد كده وعايز ترفع نسخة جديدة على GitHub، لازم كمان تزود رقم الإصدار `CACHE_NAME` في أول ملف `service-worker.js` (مثلاً من `v1` لـ `v2`) عشان المتصفح ياخد النسخة الجديدة بدل المحفوظة.
